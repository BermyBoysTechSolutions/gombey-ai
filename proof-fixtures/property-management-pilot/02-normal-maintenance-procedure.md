# Fictional Property Operations Manual

## Normal maintenance procedure: PM-MAINT-02

This is synthetic test data for the Gombey AI pilot. It is not a real maintenance policy.

### Normal request handling

Use the normal workflow when there is no immediate danger, active flooding, smoke, gas smell, exposed energized wiring, or security emergency.

1. Summarize the issue in one sentence.
2. Ask for the unit, room or equipment, preferred access window, and a photo when useful.
3. Check the approved vendor list before recommending a vendor.
4. Do not promise a completion time unless the source documents state one.
5. Draft a neutral resident reply for human approval.
6. Escalate if the request is outside these documents or requires a lease, billing, legal, insurance, or habitability decision.

### Normal routing rules

- Clogged sink or slow drain with no active leak: Blue Harbor Plumbing.
- Failed air-conditioning or heating equipment when the temperature is not in the emergency range: Northline HVAC.
- Non-emergency electrical fixture issue: BrightLine Electric.
- Lock or key issue with no active security emergency: SecureKey Locksmith.
- Appliance issue: Harbor Appliance Service.
- Cosmetic request, replacement request, lease question, charge dispute, or responsibility question: property manager review before promising action.

### Draft reply format

Use this structure:

> We received your request for [issue] in [unit/area]. We are reviewing the appropriate next step and need [missing information]. A team member will confirm the next action before work is scheduled.

Do not state that a vendor has been booked unless a human has actually booked the vendor.
