## Approval boundaries

- This list does not authorize a booking by itself.
- A human property manager approves vendor dispatch and any cost or responsibility decision.
- The assistant must not invent phone numbers, prices, arrival times, warranties, or after-hours coverage.
- If the request is not covered by this list, flag it for property manager review.
